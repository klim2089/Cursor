# Сказки для Максима

Иллюстрированные сказки на ночь для Максима (3 года 9 месяцев). Короткие фразы, повторяющиеся строчки-припевки, которые ребёнок начинает договаривать сам, и картинки в едином стиле со сквозным героем.

Откройте `index.html` в корне — это полка, с которой открываются обе книжки.

| Книжка | О чём |
| --- | --- |
| [`skazka-1-solnechnyy-kamen/`](skazka-1-solnechnyy-kamen/) | **Максим и Солнечный Камень.** Из Долины Динозавров украли камень, который всю ночь светил и грел. Максим с трицератопсом, анкилозавром и диплодоком идёт за ним в Чёрную скалу мимо спинозавра, спящего тираннозавра и велоцирапторов. |
| [`skazka-2-volshebnaya-dolina/`](skazka-2-volshebnaya-dolina/) | **Максим и Волшебная Долина Динозавров.** Сердитый Рекс отобрал у малышей мяч. Максим идёт к нему не драться, а разговаривать — и заодно выручает всех счётом, смекалкой и умением строить. |
| [`skazka-3-velikaya-dolina/`](skazka-3-velikaya-dolina/) | **Максим и малыш Чомпер.** Домашняя история по мотивам «Земли до начала времён». Максиму надоело быть маленьким, он в одиночку лезет спасать потерявшегося малыша-острозуба — и у него не выходит, пока он не зовёт друзей. |

Каждая папка устроена одинаково: `index.html` — книжка-листалка в одном файле, `skazka.md` — тот же текст документом, `images/` — иллюстрации. Внутри каждой книжки есть свой `README.md` с подсказками, как читать её вслух.

## Про героя на картинках

Мальчик нарисован с пепельно-русыми волосами (коротко по бокам, уложены набок), серо-голубыми глазами, круглым лицом с полными щеками, в кремовой пижаме с мишками и белых кроссовках — одинаково в обеих книжках. Это собирательный персонаж, а не портрет: иллюстрации не воспроизводят лицо реального ребёнка.
